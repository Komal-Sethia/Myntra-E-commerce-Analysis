# Myntra E-commerce Analysis

## Project Overview

This project presents an end-to-end analysis of Myntra e-commerce data using Microsoft Excel.

The project started with raw and uncleaned Myntra data. The data was independently cleaned, transformed, consolidated and analyzed to create meaningful business insights and interactive Excel dashboards.

The final workbook combines data preparation, KPI analysis, sales analysis, product analysis and dashboard visualization into a single analytical solution.

---

## Project Objective

The main objective of this project was to transform raw Myntra e-commerce data into a structured and interactive business analysis report.

The project focuses on:

- Understanding overall sales performance
- Analysing order and product performance
- Tracking delivered, cancelled and returned orders
- Analysing revenue and profitability
- Evaluating discounts and coupon impact
- Identifying important product and category trends
- Creating KPIs for business performance monitoring
- Building interactive Excel dashboards

---

## Data Preparation & Cleaning

The original dataset was provided in an uncleaned/raw format.

The data was independently prepared before analysis through multiple cleaning and transformation steps, including:

- Data cleaning
- Removing or handling inconsistent records
- Standardising data formats
- Handling missing values
- Formatting dates and numerical fields
- Cleaning text and categorical fields
- Checking duplicate records
- Consolidating required data
- Creating calculated fields
- Preparing the final dataset for analysis

The cleaned and transformed data was then used for pivot analysis, KPI calculations and dashboard development.

## Key Performance Indicators

The project uses important KPIs to evaluate business performance, including:

| KPI | Purpose |
|---|---|
| Total Revenue | Measures overall sales generated |
| Total Orders | Measures order volume |
| Delivered Orders | Measures successful order fulfilment |
| Returned Orders | Measures product returns |
| Cancelled Orders | Measures cancelled orders |
| Average Order Value | Measures average revenue per order |
| Return Rate | Measures the percentage of returned orders |
| Total Discount | Measures discounts provided |
| Coupon Discount | Measures coupon-based discounts |
| Net Profit | Measures overall profitability |
