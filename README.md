# Myntra E-commerce Analysis

An end-to-end e-commerce data analysis project built using Microsoft Excel, based on raw Myntra data for January–March 2026.

## Project Overview

This project started with raw and uncleaned Myntra e-commerce data.

The objective was to independently transform the raw dataset into a structured analytical solution by performing data cleaning, data transformation, analysis, KPI development, pivot-based analysis and dashboard creation.

The final Excel workbook contains the cleaned and analysed data along with two interactive dashboards designed to provide a clear view of Myntra's sales and business performance.

## Dataset

The project is based on raw Myntra e-commerce data covering:

- January 2026

- March 2026

The original dataset was provided in an uncleaned format.

The raw data was then processed and transformed to create a structured dataset suitable for analysis and dashboard development.

> Note: The original raw/source dataset is not included in this repository. The repository contains the final analytical workbook created from the raw dataset.

## Data Cleaning & Preparation

The raw Myntra dataset required multiple data preparation and cleaning steps before analysis.

### Cleaning Performed

- Reviewed the raw dataset structure
- Cleaned inconsistent data
- Standardised data formats
- Handled missing and blank values
- Checked duplicate records
- Standardised text and categorical fields
- Formatted dates
- Converted numerical fields into appropriate formats
- Prepared data for calculations and analysis
- Created required calculated fields
- Consolidated the cleaned data for reporting

The cleaned dataset was then used to build pivot tables, KPIs, charts and dashboards.

# Key Performance Indicators

| KPI | Purpose |
|---|---|
| Total Revenue | Measures overall sales generated |
| Total Orders | Measures order volume |
| Delivered Orders | Measures successfully delivered orders |
| Cancelled Orders | Measures cancelled orders |
| Returned Orders | Measures returned orders |
| Average Order Value | Measures average revenue generated per order |
| Return Rate | Measures the proportion of orders returned |
| Total Discount | Measures the overall discount amount |
| Coupon Discount | Measures discounts generated through coupons |
| Net Profit | Measures overall profitability |
